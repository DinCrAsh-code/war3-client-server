# FND-0004 — startup seed и JASS SetRandomSeed не взаимозаменяемы

| Поле | Значение |
|---|---|
| Subsystem | simulation |
| Tags | rng, startup, jass |
| Kind | contract |
| Evidence | connected |
| Verification | source-reviewed |
| State | bounded |
| Impact | correctness, compatibility |
| Scope | Game.dll 1.26.0.6401; четыре seed изолированно, ограниченные связные цепочки |
| Sources | [S06, S02](../../SOURCES.md), case 052 |

## Вывод и основание

В восстановленной startup-последовательности корневое состояние и семейство
RNG инициализируются входным seed. Оригинальный JASS `SetRandomSeed` выполняет
дополнительное извлечение из корневого генератора и использует его результат
для семейства. Эти маршруты дали разные состояния на всех четырёх проверенных
seed; источник приводит 736 сравнений слов состояния.

Ограниченная связная цепочка включает начальные данные, оригинальные
store/read сессии, декодирование, рецепт seed и последовательность команд.
Проверки сохраняют прежние наблюдаемые эффекты команд и завершение сессии.

## Ограничения

Полный обычный startup caller, lifetime входных объектов и создание
записанных объектных ссылок остаются открытыми. Изменение отдельных потоков
RNG после сценария не доказывает число вызовов и их конкретных потребителей.
Полный матч и детерминизм всех карт этим опытом не подтверждены.

## Значение и следующая проверка

В новой архитектуре одного числа seed недостаточно: важны момент
инициализации, владельцы состояния и порядок потребления. Удобный JASS-вызов
не может подменять startup без проверки эквивалентности. Следующий вопрос —
полная последовательность запуска и RNG выбранного игрового маршрута.
