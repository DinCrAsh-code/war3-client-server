# FND-NNNN — точный вывод

| Поле | Значение |
|---|---|
| Subsystem | Один код из классификатора |
| Tags | Пересекающиеся области |
| Kind | contract / boundary / negative-result / hypothesis |
| Evidence | unverified / static / isolated / connected |
| Verification | source-reviewed / reproduced / not-tested |
| State | open / bounded / contradicted / superseded |
| Impact | security / compatibility / correctness / performance / operations |
| Scope | Build, fingerprint, карта/входы, среда и покрытие |
| Sources | Документ/commit, evidence и связанный EXP, если есть |

## Вывод

Один проверяемый вывод; отделить установленное от предположений.

## Основание и контроли

Как получен результат; ожидаемое и фактическое; положительный и отрицательный
контроль. Если опыт только прочитан — явно назвать это.
