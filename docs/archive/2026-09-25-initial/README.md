- [Эскиз анатомии движка](02_anatomy.png).

Это исторические материалы, не основа новой архитектуры и не отчёт приёмки.
В изображениях есть неподтверждённые обещания: полный headless, частоты
5/25 мс и 20 Гц, фиксированная интерполяция, нагрузка на сервер, отключение
всех локальных скриптов и автоматическая совместимость карт. Пометки
«пройдено» относятся к старому эскизу, а не к продукту.

Часть вопросов первичного разбора теперь уточнена при чтении исследовательских
контрактов. Актуальные требования: [архитектура](../../ARCHITECTURE.md),
[совместимость](../../COMPATIBILITY.md), [план](../../ROADMAP.md).
Доказательства: [индекс реверса](../../../research/reverse/INDEX.md).

Архив не используется для выбора констант, статуса готовности или сроков.
