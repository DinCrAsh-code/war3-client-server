# Архитектурные решения

Здесь фиксируются решения, влияющие на границы системы, совместимость,
протокол, эксплуатацию и существенные зависимости. На 2026-09-25 принятых
технических ADR ещё нет; целевые требования находятся в
[архитектуре](../ARCHITECTURE.md).

Имя: `ADR-NNNN-short-topic.md`. Один вопрос на ADR. Статусы: `proposed`,
`accepted`, `rejected`, `superseded`. Для `accepted` указать дату и основание
решения; для `superseded` — заменяющий ADR. Агент не объявляет гипотезу
согласованным решением задним числом.

Обязательные разделы: проблема; ограничения; рассмотренные варианты;
решение и причина; влияние на старые карты, обычную игру и скрытые данные;
план проверки; источники/находки; открытые риски.

ADR ссылается на `FND-*`, но не дублирует отчёты реверса. Новое противоречащее
доказательство требует пересмотра решения и ссылок, а не удаления истории.
